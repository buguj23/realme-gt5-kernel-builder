# prebuilt/ — verified ROM inputs

Generated by `scripts/rom-stage-kernel.py` and `scripts/rom-stage-partitions.py`.

```
prebuilt/Image                                  kernel Image (from the package)
prebuilt/dtb/ossi.dtb                           stock DTBs prepared for the ramdisk fstab
prebuilt/dtbo.img                               verified stock DTBO
prebuilt/vendor_ramdisk/*.ko                    module files for normal boot and Recovery
prebuilt/vendor_dlkm/*.ko
prebuilt/system_dlkm/*.ko
prebuilt/kernel-modules.mk                      module inventories, load orders and filesystems
prebuilt/stage-report.json                      kernel provenance and staged module ABIs
prebuilt/oem_partitions/*.img                   OEM images from the verified logical layout
prebuilt/oem-partitions.mk                      dynamic partition group and A/B OTA inputs
prebuilt/oem-partitions.json                    partition layout and verified image hashes
prebuilt/fstab.ossi                             first-stage mount table
prebuilt/oem-avb-keys/*.avbpubkey                OEM keys for first-stage verification
```

Rules:

The schema 2 kernel manifest binds the OGKI Image, Module.symvers and its
modules to one build. Staging checks imports, delivered providers and vermagic
for both boot modes. AOSP generates the two load lists from the original
ordered entries in `kernel-modules.mk`.
